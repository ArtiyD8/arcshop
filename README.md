# ARCSHOP — Интернет-магазин техники и электроники (Full-Stack Монорепозиторий)

Современный интернет-магазин техники, электроники, игровой периферии и фирменного ПО с REST API на Express, хранением данных и клиентским приложением на React + TypeScript в едином монорепозитории.

---

| :--- | :--- | :--- | :--- | :--- |

| **Администратор (`ADMIN`)** | `admin` | `admin@arcshop.com` | `admin12345` | Полный доступ к административным эндпоинтам (`/api/v1/admin/*`), управлению товарами, категориями, баннерами и статусами заказов |

## Промокоды для оформления заказа

В модальном окне оформления заказа можно применить следующие промокоды:
* `ARC2026` — скидка **10%** при сумме заказа от 5 000 ₽
* `WELCOME` — скидка **5%** при сумме заказа от 1 000 ₽
* `PRODEV` — скидка **15%** при сумме заказа от 40 000 ₽

## Архитектура проекта (MVP + Модульные стили с CSS-переменными)

Проект организован по слоям архитектуры **MVP (Model – View – Presenter)**:

```text
├── docs/
│   ├── API_DOCUMENTATION.md         # Полная спецификация REST API бэкенда
│   └── BUSINESS_MODEL.md            # Бизнес-модель, потоки выручки и unit-экономика
├── server.ts                        # Точка входа единого сервера (Express API + Vite)
└── src/
    ├── server/                      # Backend (Express + персистентная БД .data/db.json)
    │   ├── app.ts                   # Инициализация Express и маршрутизация /api/v1/*
    │   ├── db.ts                    # Схема данных и файловое хранилище Store
    │   ├── middleware/              # JWT-авторизация и проверка ролей (RBAC)
    │   └── routes/                  # Модульные контроллеры REST API
    ├── model/                       # Слой Model (типы данных, схемы характеристик, API-клиент)
    │   ├── api.ts                   # HTTP-клиент для обращения к /api/v1/*
    │   ├── auth.ts                  # Сервис авторизации и профиля
    │   ├── i18n.ts                  # Словари локализации (RU / EN)
    │   ├── specs.ts                 # Схемы характеристик категорий и весов сравнения
    │   ├── theme.ts                 # Управление цветовой темой (System / Dark / Light)
    │   └── types.ts                 # Доменные интерфейсы товаров, отзывов, вопросов и заказов
    ├── presenter/                   # Слой Presenter (состояние, бизнес-логика, форматирование)
    │   ├── auth-context.tsx         # Состояние сессии пользователя
    │   ├── catalog-context.tsx      # Загрузка каталога, баннеров и поисковый запрос
    │   ├── shop-context.tsx         # Корзина, избранное, сравнение и модальное окно заказа
    │   ├── i18n-context.tsx         # Контекст локализации
    │   ├── theme-context.tsx        # Контекст темы оформления
    │   ├── compare.ts               # Алгоритм взвешенного сравнения товаров
    │   ├── format.ts                # Форматирование валюты, дат и характеристик
    │   └── use-product-link.ts      # Генерация ссылок на модальное окно товара
    ├── components/                  # Слой View — переиспользуемые компоненты по доменам
    │   ├── ui/                      # Базовые UI-элементы (Icon, Form, Popover, Stars, ThemeMenu)
    │   ├── layout/                  # Каркас приложения и выпадающие панели (Shell, ShopPanels)
    │   ├── catalog/                 # Карточки и модальное окно товара (ProductCard, ProductModal, ProductTabs, ProductImage)
    │   └── checkout/                # Модальное окно оформления заказа (CheckoutModal)
    ├── pages/                       # Слой View — страницы по доменам
    │   ├── catalog/                 # Каталог и умное сравнение (CatalogPage, ComparePage)
    │   ├── orders/                  # История заказов пользователя (OrdersPage)
    │   ├── auth/                    # Вход и регистрация (LoginPage, RegisterPage)
    │   └── account/                 # Настройки профиля и безопасности (SettingsPage)
    └── styles/                      # Модульные CSS-файлы на базе CSS-переменных
        ├── base.css                 # Палитра CSS-переменных (Light/Dark), сброс и базовая типографика
        ├── app.css                  # Каркас, сайдбар, шапка, поиск, формы и выпадающие панели
        ├── shop.css                 # Каталог, карточки товаров, модалка товара, отзывы и сравнение
        ├── checkout.css             # Стили модального окна оформления заказа
        └── orders.css               # Стили страницы истории заказов
```
